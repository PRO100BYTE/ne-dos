# NE-DOS Documentation

Welcome to the NE-DOS project documentation. NE-DOS is a browser-based DOS-like terminal emulator built with React and xterm.js, featuring a BrowserFS-backed virtual filesystem.

- [Changelog](./changelog.md) — version history
